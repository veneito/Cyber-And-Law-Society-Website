# Investigation desktop (`/activity`)

A GNOME-style virtual desktop (`src/components/ActivityDesktop.tsx`) behind a "Start activity" button, which also asks for fullscreen. Wallpaper: `public/assets/desktop-wallpaper-v1.png` (new filename if replaced).

## Scenario (player-facing, in `README.txt` on the desktop)
The player is an investigator searching for a missing woman, using social media to find her last known locations. Suspicious locked flash drives were found in her room.

## Progression (designer notes, not shown to players)
1. Read the README.
2. Browse the fake social media page.
3. Work out the last person who had contact with her: her ex.
4. Investigate the ex's profile; find out he is in a cult.
5. Decipher the first flash drive password.
6. That drive holds "deep-web"-style links tied to the ex's cult.
7. Those sites hold cyber puzzles whose answer is the next USB password.
8. Continued later.

## Status
Shell and README only; Files, Terminal and Notes are empty placeholders. Social media page, drives and puzzles are not built.
